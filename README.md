# MVP сайт SmailAgent

Демо-прототип на чистом `HTML/CSS/JavaScript` с хранением данных в `localStorage`.

## Что реализовано

- Портфолио с фотографиями (`public/portfolio/*.jpg`).
- Онлайн-календарь занятых слотов.
- Регистрация и авторизация клиентов.
- Конструктор программы с выбором аниматоров и расчетом цены.
- Бронирование даты/времени с проверкой занятости.
- Имитация онлайн-оплаты.
- Админ-панель для просмотра и редактирования заказов.
- Авторизация админа (демо): `admin / admin123`.
- Telegram-уведомления при новых бронированиях (через Bot API).

## Как запустить

Из папки проекта (рекомендуется, без Node):

```powershell
python server.py
```

Альтернатива через Node.js:

```powershell
npm install
npm start
```

Откройте:

- Главная: `http://localhost:8080/index.html`
- Портфолио: `http://localhost:8080/portfolio.html`
- Бронирование (календарь + конструктор): `http://localhost:8080/booking.html`
- Детали портфолио: `http://localhost:8080/portfolio-detail.html?type=birthday`
- Админка: `http://localhost:8080/admin.html`

## Настройка Telegram

1. Войдите как `admin`.
2. Откройте `admin.html`.
3. В блоке Telegram укажите:
   - `Bot Token`
   - `Chat ID`
4. После этого новые заказы будут отправляться в Telegram.

## Важно для демо

- Это MVP-прототип без серверной защиты.
- Пароли и заказы хранятся локально в браузере.
- Фото, загруженные из админских форм, теперь сохраняются на сервере в `public/portfolio/`.
- Для реального запуска нужен backend + БД + безопасная авторизация.
